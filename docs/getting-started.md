# Start a project

1. Choose **File → New Project…**.
2. Enter the project name, then click **Choose Location & Create**.
3. Select the parent folder. Grimoire Maker creates a new folder with your project name and opens it.

The new folder contains `Draft/Chapter 1/Welcome.md` (the demo), `Research`, and `Trash`.
An existing folder with the same name is never replaced. Canceling the location picker keeps the form open.

Use **File → Open Folder…** to open an existing project. Existing projects do not receive another demo.
Use **File → New File…** to choose a name and location for a new Markdown file, opened in a new tab.
The default location follows the selected Draft/Research section or the active file. Existing files are not overwritten.
