# Documents and split view

Opening a Markdown file keeps existing tabs open. Each tab retains its own text,
unsaved indicator, selection, undo history, and scroll position until closed.
Switching tabs does not discard or reload its buffer from disk. Use **Save** for
the focused document; closing a dirty tab saves that document first.

Use **Split View**, beside **Ruler**, to show two independent editable views.
Click inside a view before choosing a tab or opening a file. A document is shown
in only one view; choosing the other view's document swaps their assignments.
Formatting, image insertion, snippets, preview, and PDF export target the focused
view. Page size, theme, and print settings remain shared application settings.

Switching projects or closing the desktop window saves all dirty documents. A
failed save, cancelled Save As, or edit made during saving keeps the document open.
External file changes are not automatically reloaded over an open buffer; close
and reopen a clean tab to read disk changes. This is not crash-recovery autosave.
