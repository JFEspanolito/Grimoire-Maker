# Poetry Collection

This folder is a multi-document template package for poetry collections and lyric anthologies.

## Included structure

- `index.md` — Collection overview and contents.
- `chapters/Cover and Title.md` — Half-title, main title, and colophon metadata.
- `chapters/Dedication and Prologue.md` — Epigraph, dedication, and introductory note.
- `chapters/Part I - Light/01 - Dawn.md` — Opening poem of the first movement.
- `chapters/Part I - Light/02 - Noon.md` — Second poem of the first movement.
- `chapters/Part II - Shadows/03 - Dusk.md` — Opening poem of the second movement.
- `chapters/Part II - Shadows/04 - Midnight.md` — Closing poem of the second movement.
- `chapters/Closing/Epilogue.md` — Author's afterword and compositional notes.
- `chapters/Closing/Index of First Lines.md` — Alphabetical index of opening verses.

## Create your own

Copy this folder under `Mods/Templates/<your-id>/`, edit `templateName` in `index.md`, and organize poems under `chapters/` by thematic sections.
