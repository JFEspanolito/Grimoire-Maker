# Daily Workflow

1. **Sync Workspace**: Pull the latest changes or open your active project folder from the sidebar.
2. **Draft & Structure**: Organize new sections inside numbered folders so navigation order remains deterministic.
3. **Review & Export**: Inspect pagination in dual-page or print view before generating the distribution build.
