# Best Practices

:::box{width="100%" align="center" background="#eff6ff"}
**Tip — Keep Documents Modular**  
Split large manuals into focused topic files under numbered directories (`01 - ...`, `02 - ...`). Smaller files are easier to review, diff in version control, and reorganize.
:::

- Use consistent YAML frontmatter (`title`, `pageSize`, `columns`, `theme`) across every file in a manual.
- Store shared diagrams and screenshots inside the project's `Assets/` folder.
- Update the revision history table whenever an operational procedure changes.
