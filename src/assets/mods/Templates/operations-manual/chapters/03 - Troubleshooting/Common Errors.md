# Common Errors

| Symptom | Probable Cause | Resolution |
| --- | --- | --- |
| **Missing custom template in catalog** | Package folder lacks `index.md` or valid `templateName` frontmatter | Ensure `index.md` exists at the root of the template folder and click **Refresh** |
| **Broken image link in preview** | Asset moved outside the active project directory | Place images inside the project folder and re-insert via the toolbar |
| **Unexpected page overflow** | Oversized fixed-width table or unsplit content box | Reduce box width percentage or split long tables across sections |
