# Initial Walkthrough

1. **Create the Workspace Folder**: Initialize a dedicated project directory on your local drive.
2. **Verify Configuration Paths**: Open **Settings → Library Paths** to confirm where templates, snippets, and backups are stored.
3. **Run the Smoke Check**: Create a test document, export a preview PDF, and confirm all fonts render cleanly.
