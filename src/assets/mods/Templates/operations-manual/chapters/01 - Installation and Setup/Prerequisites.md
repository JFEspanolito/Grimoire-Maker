# Prerequisites

Before beginning installation, verify that the target workstation meets the following baseline requirements:

| Requirement | Minimum Specification | Recommended |
| --- | --- | --- |
| **Operating System** | Windows 10 (64-bit) / macOS 13 / Linux | Latest stable LTS release |
| **Memory (RAM)** | 8 GB | 16 GB or higher |
| **Disk Space** | 2 GB free storage | NVMe SSD with 10 GB free |
| **Permissions** | Standard user read/write in workspace | Local administrator for driver setup |
