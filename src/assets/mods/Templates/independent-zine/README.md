# Independent Zine

This folder is a multi-document template package for independent zines, art booklets, and thematic micro-magazines.

## Included structure

- `index.md` — Issue overview and contents.
- `chapters/Cover.md` — Issue masthead, number, and cover headline.
- `chapters/Manifesto and Editorial.md` — Opening letter from the editors.
- `chapters/Feature Article/Part 1 - Central Essay.md` — Primary long-form piece.
- `chapters/Feature Article/Part 2 - Gallery and Commentary.md` — Visual spread and critical notes.
- `chapters/Contributions/Guest Poem or Short Story.md` — Invited fiction or lyric piece.
- `chapters/Contributions/Interview.md` — Q&A conversation with a featured creator.
- `chapters/Back Cover and Contact.md` — Colophon, print run specs, and submission address.

## Create your own

Copy this folder under `Mods/Templates/<your-id>/`, edit `templateName` in `index.md`, and customize the issue pages inside `chapters/`.
