# TTRPG Core Rulebook / Homebrew Manual

This folder is a multi-document template package for tabletop roleplaying game core rulebooks, setting sourcebooks, and homebrew compendiums.

## Included structure

- `index.md` — Rulebook overview and master table of contents.
- `chapters/00 - Preliminaries/` — Cover, title page, credits, and open gaming license declarations.
- `chapters/01 - Introduction/` — Game tone, core pillars, and fundamental dice mechanics.
- `chapters/02 - Character Creation/` — Step-by-step creation, origins, classes, talents, and starting gear.
- `chapters/03 - Core Rules System/` — Check resolution, exploration cycles, tactical combat, and conditions.
- `chapters/04 - Special Subsystems/` — Magic, psionics, or technology frameworks and power catalogs.
- `chapters/05 - Game Master Guide/` — Adjudication principles, encounter/zone design, and campaign rewards.
- `chapters/Appendix A - Bestiary/` — Statblock anatomy and categorized adversary entries.
- `chapters/Appendix B - Items and Equipment/` — Mundane gear tables and rare relics.
- `chapters/Quick Reference/` — Back-cover rules summary and alphabetical index.

## Create your own

Copy this folder under `Mods/Templates/<your-id>/`, edit `templateName` in `index.md`, and customize the chapters you need inside `chapters/`.
