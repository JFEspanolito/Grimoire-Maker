| Skill | Governing Attribute | Common Uses |
| --- | :---: | --- |
| **Athletics** | Might | Climbing, grappling, forced marches, swimming |
| **Finesse** | Agility | Lockpicking, sleight of hand, disabling mechanisms |
| **Lore** | Intellect | History, arcane traditions, deciphering scripts |
| **Survival** | Instinct | Tracking, foraging, navigating hazards |
