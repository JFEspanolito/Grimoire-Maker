# Glossary

| Term | Definition |
| --- | --- |
| **MTTR** | Mean Time to Recovery following a service-impacting incident. |
| **p95 Latency** | The 95th percentile response duration across all sampled requests. |
| **Warm Standby** | A secondary region running scaled-down compute ready to absorb full traffic on failover. |
