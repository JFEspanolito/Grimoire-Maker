# Executive Report

This folder is a multi-document template package for formal audits, technical assessments, and executive business reports.

## Included structure

- `index.md` — Report overview and section directory.
- `chapters/Cover and Metadata.md` — Document control table, authorship, and classification.
- `chapters/Executive Summary.md` — Key takeaways and decision brief.
- `chapters/01 - Context/Background.md` — Operational history and problem statement.
- `chapters/01 - Context/Objectives and Scope.md` — Success criteria and in-scope boundaries.
- `chapters/02 - Analysis/Methodology.md` — Evaluation framework and data sources.
- `chapters/02 - Analysis/Findings and Data.md` — Quantitative observations and benchmarks.
- `chapters/03 - Action Plan/Proposal and Roadmap.md` — Phased implementation plan.
- `chapters/03 - Action Plan/Budget and Risks.md` — Resource allocation and risk matrix.
- `chapters/Conclusions.md` — Final recommendations and sign-off.
- `chapters/Appendices/Glossary.md` — Definitions of technical and domain terms.
- `chapters/Appendices/Data Tables.md` — Supplemental reference datasets.

## Create your own

Copy this folder under `Mods/Templates/<your-id>/`, edit `templateName` in `index.md`, and customize the sections inside `chapters/`.
