# Data Collection Instruments

Appendices contain complete, unabridged versions of measurement instruments deployed during the research, enabling independent replication and methodological auditing.

## Included Instruments

Include the full text, layout, and scoring guidelines for all instruments:

1. **Questionnaires and Psychometric Scales**:
   - Complete item wording, introduction script, response scales (e.g., 5-point Likert scale anchors), and reverse-coded item indicators.
2. **Semi-Structured Interview Guides**:
   - Complete thematic question outlines, probe prompts, opening framing statements, and closing remarks.
3. **Observation Rubrics and Checklists**:
   - Behavioral categories, scoring rubrics, time-sampling intervals, and observer instructions.
4. **Benchmarking and Test Scripts**:
   - Hardware specifications, network topology diagrams, configuration flags, and automation test scripts.
